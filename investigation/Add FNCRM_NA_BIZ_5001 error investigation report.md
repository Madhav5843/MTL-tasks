## Simple Explanation of What Happened

### Error Observed

```text
FNCRM_NA_BIZ_5001
```

This error was being generated by:

```text
mtl-nice-actimize-fin-crime-service
```

which is the Financial Crime Service.

## Investigation Flow

### 1. Search Error in CloudWatch

Query:

```sql
fields @timestamp, @message
| filter @message like "FNCRM_NA_BIZ_5001"
| sort @timestamp desc
| limit 100
```

Purpose:

* Check whether the error exists
* Identify impacted service

Result:

```text
FNCRM_NA_BIZ_5001 confirmed
Financial Crime Service identified
```

***

### 2. Check Error Frequency

Query:

```sql
fields @timestamp, @message
| filter @message like "FNCRM_NA_BIZ_5001"
| stats count(*) as occurrences by bin(1h)
```

Result:

```text
~614 occurrences
```

Meaning:

This is not a one-time failure.

The application keeps receiving requests that fail validation.

### 3. Check Exception Type

FNCRM_NA_BIZ_5001

Meaning:

The application intentionally rejected the request because data validation failed.

Not a system outage.

Not a database failure.

### 8. Find Exact Failure Point

Found:

```text
ActimizeConnector.validateTownOrCity()
```

Error:

```text
TownOrCity validation error occurred
```

***

## Root Cause

The failure occurs inside:

```java
ActimizeConnector.validateTownOrCity()
```

because the payload contains:

```text
Invalid Town value
OR
Invalid City value
OR
Missing Town/City value
```

Example:

Valid:

```json
{
 "townOrCity": "London"
}
```

Invalid:

```json
{
 "townOrCity": ""
}
```

or

```json
{
}
```

or

```json
{
 "townOrCity": null
}
```

## Final Root Cause Statement

> The error FNCRM\_NA\_BIZ\_5001 is caused by an application-level validation failure in `ActimizeConnector.validateTownOrCity()`. The Financial Crime Service receives a request containing invalid, empty, or missing Town/City information and rejects the request. The failed message is subsequently routed to `ebs-prd-dlq-na-checks-request-queue.fifo`. No AWS infrastructure, EKS, SQS, networking, or platform-related issues were identified.
