Section 1: Introduction to Git and GitHub – 
Combined Summary
Overview
This section introduces Git and GitHub, explaining what they are, why they are 
used, and how to set them up. It covers version control, collaboration, backups, 
and installation of Git.
Main Concepts
Git
A version control system installed locally on your computer.
Tracks changes in your project files over time.
Allows you to record snapshots (commits) of your project, which can be used 
to revert to previous states.
Useful for managing code efficiently instead of relying on undoing changes 
manually.
GitHub
An online hosting service for Git repositories.
Stores your project files and commit history online.
Supports collaboration: multiple contributors can work on a project, upload 
changes, and merge them.
Acts as a backup so you can retrieve files if your local copy is lost.
Repositories can be private (restricted access) or public (shared with 
everyone).
