## 2. Install Git

Git is installed on your **local computer**.

Official website: [Git Downloads](https://git-scm.com/downloads)

Git provides installers or installation instructions for:
- Windows
- macOS
- Linux

Choose the instructions for your operating system.

---

## 3. Install Git on macOS

The course uses **Homebrew** to install Git on a Mac.

### What is Homebrew?

**Homebrew is a package manager for macOS.** It allows you to install software from the Terminal.

### Step 1: Install Homebrew

Visit [Homebrew](https://brew.sh/). Copy the current installation command shown on its official website and run it in Terminal.

You may need to enter your Mac administrator password.

### Step 2: Install Git

After Homebrew is installed, run:

```bash
brew install git
```

### Step 3: Verify Git

Run:

```bash
git
```

If Git is installed correctly, this displays Git help/usage information. You can also check the installed version with:

```bash
git --version
```

---

## 4. Install Git on Linux

Git can be installed using the package manager for your Linux distribution.

For example, on Ubuntu or Debian:

```bash
sudo apt update
sudo apt install git
```

Then verify the installation:

```bash
git --version
```

Running `git` by itself can also display help/usage information.

> **Note:** Commands vary by distribution. The commands above are for Ubuntu/Debian-based systems.

## 5. Install Git on Windows

Visit the official [Git for Windows download page](https://git-scm.com/download/win) and download the appropriate installer, typically the **64-bit Windows installer** for a standard 64-bit PC.

Open the downloaded installer and follow the setup screens.

### Windows installation options

#### 1. Installation location

Choose where Git should be installed. For most beginners, keeping the **default location** is fine.

#### 2. Default editor

Git asks which text editor it should use for messages and other text-based tasks.

The course chooses **Notepad++**. You can choose an editor you already use or feel comfortable with.

#### 3. Default branch name

The installer may ask what the initial branch should be called. The course selects:

```text
main
```

`main` is a common default branch name today, but Git repositories are not required to use it.

#### 4. Other options

For beginners, keep the default options unless you have a specific reason to change them.

A simplified installation flow:

```text
Next
  ↓
Next
  ↓
Next
  ↓
Install
  ↓
Finish
```

Some screens may differ depending on the Git for Windows installer version.

---

## 6. Verify Git Installation

After installation, open **Command Prompt**, **PowerShell**, or **Git Bash** on Windows. On macOS or Linux, open Terminal.

Run:

```bash
git --version
```

Example output:

```text
git version 2.x.x
```

The exact version number will vary. If a Git version is displayed, Git is installed and available in that terminal.

## 9. DevOps Note

Remember the distinction:

```text
GitHub
   ↑
   │ git push
   │
 Git
   ↑
   │
Your project files
```

**Git runs on your machine. GitHub is the remote platform where you can store and collaborate on Git repositories.**
