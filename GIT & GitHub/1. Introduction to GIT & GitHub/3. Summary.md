# 📘 Section 1: Introduction to Git & GitHub

## 1. Git

**Git = Version Control System (VCS)**

Git is software installed on your **local computer** that tracks changes made to project files.

### What Git does

- Tracks changes in files
- Maintains project history
- Creates **commits/snapshots**
- Allows you to go back to previous versions
- Helps manage code efficiently

### Example

```text
Project
  ↓
Make changes
  ↓
Commit
  ↓
Make more changes
  ↓
Commit
  ↓
Project history
```

---

# 2. GitHub

**GitHub = Online hosting platform for Git repositories**

GitHub stores your project and its Git history online.

### What GitHub provides

- ☁️ Remote storage
- 🤝 Collaboration
- 💾 Backup
- 📜 Commit/version history
- 🌍 Public repositories
- 🔒 Private repositories

### Simple difference

> **Git = tracks changes locally**  
> **GitHub = hosts those changes online**

---

# 3. Git + GitHub

The basic relationship:

```text
Your Computer
     │
     │ Git
     ↓
Local Repository
     │
     │ Push
     ↓
   GitHub
```

Other developers can get the project from GitHub and work on it.

```text
Developer A ──┐
              ↓
           GitHub
              ↑
Developer B ──┘
```

---

# 4. Important Terms

### Commit

A **snapshot of your project at a specific point in time**.

```text
Commit 1 → Created project
Commit 2 → Added login
Commit 3 → Fixed bug
Commit 4 → Added dashboard
```

---

### Repository / Repo

A **repository** is a project managed by Git.

It contains:

```text
Project files
+
Git history
+
Commits
```

---

### Contributor

A person who contributes code or changes to a repository.

---

### Snapshot

Another way of describing a **commit**.

> **Commit = Snapshot of the project**

---

# 5. GitHub Repository Types

### 🔒 Private Repository

Only authorized users can access it.

Used for:

- Company projects
- Internal applications
- Private code

### 🌍 Public Repository

Anyone can view it.

Used for:

- Open-source projects
- Portfolios
- Sharing projects with employers

# 8. Why Do We Need Git?

### Without Git

```text
Code → Change → Something breaks 😵
             ↓
       Manually undo
```

### With Git

```text
Code
 ↓
Commit
 ↓
Make changes
 ↓
Something breaks
 ↓
Use Git history
 ↓
Restore previous version
```

# ⭐ Section 1 Key Takeaways

Remember these **5 points**:

1. **Git is a version control system.**
2. **Git tracks changes locally.**
3. **A commit is a snapshot of your project.**
4. **GitHub hosts Git repositories online.**
5. **GitHub enables backup and collaboration.**
