Creating a Git Repository

## 1. Starting a New Project

Whenever you start a new coding project, you normally create/open a project in an IDE such as:

- Visual Studio Code
- PyCharm

Example:

```text
git_course/
```

At this point, **Git is not yet enabled** for the project.

---

# 2. Enable Git for the Project

To start using Git, you need to create a **Git repository**.

Open the terminal inside your project folder and run:

```bash
git init
```

### What does `git init` do?

It **initializes a new Git repository** in the current directory.

You will see something like:

```text
Initialized empty Git repository...
```

---

# 3. What Happens After `git init`?

Git creates a hidden folder called:

```text
.git
```

Example:

```text
git_course/
│
├── .git/
├── app.py
└── README.md
```

The `.git` folder contains Git's internal information and history for that project.

### Important ⚠️

You normally **do not manually modify or work inside `.git`**.

Git manages it automatically.

---

# 4. What Does `.git` Store?

The `.git` directory contains information Git needs to manage your repository, including:

- Repository configuration
- Commit history
- Information about changes
- Branch information
- Other Git metadata

Conceptually:

```text
.git
 │
 ├── Configuration
 ├── Commit history
 ├── Branch information
 └── Git metadata
```

---

# 5. How Git Tracks Your Project

After initializing Git, you can start writing code.

For example:

```text
Step 1
  ↓
Create project
  ↓
git init
  ↓
Start coding
  ↓
Make changes
  ↓
Create commits
  ↓
Git tracks project history
```

Each **commit represents a state/snapshot of your project** at a particular point in time.

Example:

```text
Commit 1
↓
Initial project

Commit 2
↓
Added login

Commit 3
↓
Fixed login

Commit 4
↓
Added database
```

---

# 6. How to Check the Hidden `.git` Folder

Normally `.git` is hidden.

### Linux / macOS

```bash
ls -la
```

### Windows CMD

```cmd
dir /a
```

### Windows PowerShell

```powershell
dir -Force
```

You should see:

```text
.git
```

---

# 7. Important Command

### `git init`

```bash
git init
```

**Meaning:**

> Initialize the current directory as a Git repository.

This is usually one of the **first Git commands** you run when starting a new project.

---

# 🧠 Simple Flow to Remember

```text
Create Project
      ↓
Open Terminal
      ↓
git init
      ↓
.git folder created
      ↓
Git Repository Ready
      ↓
Write Code
      ↓
Track Changes
      ↓
Create Commits
```

---

# ⭐ Key Takeaways

1. **`git init` initializes Git in a project.**
2. Git creates a hidden **`.git` directory**.
3. `.git` contains Git's internal configuration and history.
4. You normally **don't modify `.git` manually**.
5. After `git init`, your project is ready to start using Git.
6. **Commits are snapshots of the project's state over time.**

### 🔑 One-line memory trick

> **`git init` = "Git, start tracking this project."**
